## Xem local

Mở trực tiếp `index.html` trong trình duyệt, hoặc chạy server tĩnh:

```bash
python3 -m http.server 8000
```

Sau đó truy cập `http://localhost:8000`.

- **Vercel:** <https://portfolio-long-leo.vercel.app>
